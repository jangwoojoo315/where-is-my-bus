# where-is-my-bus (버스 도착 정보)

경기도 정류장과 그 정류장에 서는 버스를 등록하면, 등록한 버스가 **몇 분 뒤에 도착하는지**만 보여주는 크롬 확장 프로그램입니다. 알림/알람 같은 부가 기능은 없습니다.

## 동작 방식

- 공공데이터포털(data.go.kr)의 **경기도 버스정보(GBIS)** API를 사용합니다. (제공기관 코드 6410000)
- 경기도 지역 정류장/버스를 대상으로 합니다. (서울은 미지원)
- 도착정보는 팝업을 열 때마다, 그리고 열려 있는 동안 30초마다 갱신됩니다.

## 설치 (개발자 모드)

1. 크롬에서 `chrome://extensions` 접속
2. 우측 상단 **개발자 모드** 켜기
3. **압축해제된 확장 프로그램을 로드** 클릭 → 이 폴더(`where-is-my-bus`) 선택

## API 키 발급

1. [공공데이터포털](https://www.data.go.kr) 회원가입/로그인
2. 다음 API들에 **활용신청**(제공기관: 경기도):
   - **경기도_버스정류소조회** (정류소 이름 검색)
   - **경기도_정류소 경유노선 목록조회** (정류장의 버스 노선 목록)
   - **경기도_버스도착정보조회** (도착 예정 정보)
3. 마이페이지 → 인증키 발급 현황에서 **일반 인증키(Decoding)** 복사

> - 인코딩 키가 아니라 **Decoding(디코딩) 키**를 입력하세요. (앱이 자동으로 인코딩 처리)
> - 승인 후 키가 활성화되기까지 시간이 걸릴 수 있습니다. 그동안은 403/401이 날 수 있습니다.

## API 키 설정 (둘 중 하나)

- **방법 A — config.js (권장)**: `config.example.js`를 복사해 `config.js`로 만들고 키를 넣습니다.
  ```bash
  cp config.example.js config.js   # 그 후 config.js 의 API_KEY 에 키 입력
  ```
  `config.js`는 `.gitignore`로 git에 올라가지 않습니다.
- **방법 B — 옵션 화면**: 확장 옵션 화면 "1. API 키 설정"에 키를 붙여넣고 저장. (`chrome.storage`에 저장)

## 사용법

1. 확장 프로그램 아이콘 우클릭 → **옵션**, 또는 팝업의 ⚙ 버튼
2. **2. 정류장 / 버스 추가**: 정류장 이름 검색 → 정류장 선택 → 표시되는 노선 목록에서 버스 선택
3. 툴바 아이콘을 누르면 등록한 버스의 도착 정보가 표시됩니다.

## 파일 구조

| 파일 | 설명 |
|------|------|
| `manifest.json` | 확장 프로그램 설정 (MV3) |
| `api.js` | GBIS API 호출 및 저장소 모듈 |
| `config.js` | API 키 (git 제외) — `config.example.js` 복사해서 생성 |
| `popup.html/.css/.js` | 도착 정보 표시 팝업 |
| `options.html/.css/.js` | API 키·정류장·버스 등록 화면 |
| `icons/` | 확장 프로그램 아이콘 |

## 참고

- 일부 정류장/노선은 실시간 도착정보가 제공되지 않을 수 있으며, 그 경우 "운행 정보 없음"으로 표시됩니다.
- 등록 정보(즐겨찾기, 옵션에서 입력한 키)는 `chrome.storage.sync`에 저장되어 같은 크롬 계정 간 동기화됩니다.
