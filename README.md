# where-is-my-bus (버스 도착 정보)

서울·경기 정류장과 그 정류장에 서는 버스를 등록하면, 등록한 버스가 **몇 분 뒤에 도착하는지**만 보여주는 크롬 확장 프로그램입니다. 알림/알람 같은 부가 기능은 없습니다.

## 동작 방식

- 공공데이터포털(data.go.kr)의 **국토교통부 TAGO 전국버스정보** API를 사용합니다.
- 서울·경기를 포함한 전국 정류장을 하나의 API 키로 조회합니다.
- 도착정보는 팝업을 열 때마다, 그리고 열려 있는 동안 30초마다 갱신됩니다.

## 설치 (개발자 모드)

1. 크롬에서 `chrome://extensions` 접속
2. 우측 상단 **개발자 모드** 켜기
3. **압축해제된 확장 프로그램을 로드** 클릭 → 이 폴더(`where-is-my-bus`) 선택

## API 키 발급

1. [공공데이터포털](https://www.data.go.kr) 회원가입/로그인
2. 다음 두 API에 **활용신청**:
   - **국토교통부_(TAGO)_버스정류소정보** (정류소 검색 / 도시코드)
   - **국토교통부_(TAGO)_버스도착정보** (도착 예정 정보)
3. 마이페이지 → 인증키 발급 현황에서 **일반 인증키(Decoding)** 복사

> 인코딩 키가 아니라 **Decoding(디코딩) 키**를 입력하세요. (앱이 자동으로 인코딩 처리합니다.)

## 사용법

1. 확장 프로그램 아이콘 우클릭 → **옵션**, 또는 팝업의 ⚙ 버튼
2. **1. API 키 설정**: 발급받은 디코딩 키 붙여넣고 저장
3. **2. 정류장 / 버스 추가**: 도시 선택 → 정류장 이름 검색 → 정류장 선택 → 버스 번호 입력 → 추가
4. 툴바 아이콘을 누르면 등록한 버스의 도착 정보가 표시됩니다.

## 파일 구조

| 파일 | 설명 |
|------|------|
| `manifest.json` | 확장 프로그램 설정 (MV3) |
| `api.js` | 공공데이터 API 호출 및 저장소 모듈 |
| `popup.html/.css/.js` | 도착 정보 표시 팝업 |
| `options.html/.css/.js` | API 키·정류장·버스 등록 화면 |
| `icons/` | 확장 프로그램 아이콘 |

## 참고

- TAGO API는 일부 지역에서 실시간 도착정보가 제공되지 않을 수 있으며, 그 경우 "운행 정보 없음"으로 표시됩니다.
- 등록 정보(API 키, 즐겨찾기)는 `chrome.storage.sync`에 저장되어 같은 크롬 계정 간 동기화됩니다.
